# 📝 Word Counter

## 📌 About the Project
Word Counter built using HTML, CSS, and JavaScript. It allows users to count words, calculate text length, remove extra spaces, and convert text into uppercase or lowercase.

## ✨ Features
- 🔢 **Word Counter:** Counts the total number of words.
- ✂️ **Trim Text:** Removes extra spaces from the beginning and end of the text.
- 🔠 **Uppercase:** Converts text into uppercase letters.
- 🔡 **Lowercase:** Converts text into lowercase letters.
- 📏 **Count Length:** Counts the total number of characters.
- ⚡ **Simple Interface:** Easy to use and beginner-friendly.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter your text in the text area.
5. Use the available buttons to count words, trim spaces, change letter case, and count characters.
